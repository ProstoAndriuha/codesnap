# Подключение почты в CodeSnap 0.7.2

Gmail подключается официальным входом Google, без локального модуля. Можно добавлять несколько аккаунтов; дополнительные аккаунты используют временную сессию и могут потребовать повторного входа. Тестовый режим Google OAuth ограничивает список пользователей.

Yahoo, Яндекс, Mail.ru и ручной IMAP требуют Windows, Python 3 и отдельного модуля CodeSnap-Mail-Setup.zip из GitHub Releases. Распакуйте архив, откройте PowerShell в его папке и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-mail-helper.ps1
```

Модуль регистрируется только для текущего пользователя Windows. Затем обновите расширение в chrome://extensions. В меню почты выберите сервис, укажите адрес и пароль приложения. Для Яндекса включите IMAP и создайте пароль приложения для почты; обычный пароль может не работать. У каждого сервиса есть ссылка на его официальную инструкцию прямо в форме.

Подключение проверяется до сохранения. Пароли хранятся зашифрованными Windows DPAPI в %LOCALAPPDATA%\CodeSnap\Mail\accounts.dpapi. Локальный модуль не открывает сетевой порт. Поиск читает только недавние письма во «Входящих», не помечает их прочитанными и не отправляет/удаляет письма. Коды из спама или других папок нужно переместить во «Входящие».

После замены файлов расширения нажмите «Обновить» в chrome://extensions. Ошибка Unknown request означает, что фоновая часть браузера ещё использует предыдущую версию.

Модуль сейчас разрешает только прежний ID распакованного CodeSnap. Для версии магазина потребуется отдельно настроить фактический ID магазина. Outlook временно недоступен и убран из меню подключения.
