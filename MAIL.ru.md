# Почта без установки программ — CodeSnap 0.8.2

Gmail подключается напрямую кнопкой Google. Для остальных сервисов включите «Почта через CodeSnap Cloud» в настройках.

Яндекс: выберите «Яндекс», подтвердите обработку через Cloud в форме и нажмите «Войти через Яндекс». Официальная страница запросит адрес почты и право только на чтение писем. Пароль приложения можно использовать как запасной вариант.

Yahoo и Mail.ru: создайте пароль приложения у провайдера, введите адрес и этот пароль в расширении. Ручной IMAP: публичный сервер с SSL/TLS 993 или STARTTLS 143; внутренние адреса и другие порты не принимаются. Outlook пока убран.

Никаких Python, CodeSnap-Mail-Setup.zip и локальных помощников. Пароли и OAuth-токены шифруются на сервере. Gmail-токены туда не передаются. IMAP читает только Входящие за последние 15 минут, до 40 последних писем; письма больше 256 КБ пропускаются. Максимум 20 облачных аккаунтов на эту копию расширения.

Удалите выбранный аккаунт в расширении, чтобы удалить его данные подключения с сервера. Выключение Cloud только приостанавливает чтение. Перед удалением расширения сначала отключите аккаунты. Если доступ к расширению потерян, отзовите OAuth-разрешение или пароль приложения у провайдера.

Старый локальный помощник больше не используется; его прежнее хранилище не переносится автоматически. Никакие ваши реальные письма не являются частью опубликованных тестов.

## Разделение пользователей
Каждая установка в профиле браузера создаёт отдельный случайный 256-битный ключ доступа. Сервер хранит подключения по хешу этого ключа, а не по общему ID расширения или общему списку почтовых адресов. Просмотр, поиск кодов и удаление доступны только владельцу ключа; даже известный ID чужого подключения не даёт доступа. Кэш писем также разделён по владельцу и аккаунту.

Отдельного входа в кабинет CodeSnap и синхронизации между устройствами пока нет. Повторное включение Cloud в том же профиле возвращает сохранённые подключения. «Удалить выбранный» удаляет данные подключения этого аккаунта; после последнего аккаунта удаляется весь зашифрованный файл владельца.
