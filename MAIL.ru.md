# Почта и 2FA 100% локально — CodeSnap 1.4.0

В версии 1.4.0 всё работает исключительно внутри вашего браузера (без серверов CodeSnap и без Python/помощников). Поддерживаются мгновенный Push из открытых вкладок 12 почт (включая `Gmail Web` бесплатно), прямой Google / Gmail OAuth и безлимит 2FA по офлайн-ключу **CodeSnap Pro (`Ed25519` `CS1-…`)**, офлайн-QR на телефон (`📱`), автопоправка сдвига часов (`⏱`), раскладка кода по ячейкам (`📋`), Withdraw Check, Smart Grace Wait, Антифишинг-щит, Снайпер QR и ручное указание поля.

## Поддерживаемые почтовые сервисы

1. **Google / Gmail (прямой Google OAuth)** — работает без открытой вкладки Gmail, поддерживает основной и дополнительные аккаунты Google.
2. **Локальное чтение открытых вкладок почты (без паролей и серверов)**:
   - **Яндекс Почта** (`mail.yandex.ru`, `mail.yandex.com`, `360.yandex.ru`)
   - **Outlook / Hotmail / Microsoft 365** (`outlook.live.com`, `outlook.office.com`, `outlook.cloud.microsoft`)
   - **Yahoo Mail** (`mail.yahoo.com`)
   - **Mail.ru** (`e.mail.ru`, `octavius.mail.ru`)
   - **Proton Mail** (`mail.proton.me`)
   - **iCloud Mail** (`www.icloud.com/mail`)
   - **Zoho Mail** (`mail.zoho.com`, `.eu`, `.in`)
   - **Рамблер/почта** (`mail.rambler.ru`)
   - **Fastmail** (`app.fastmail.com`)
   - **AOL Mail** (`mail.aol.com`)
   - **GMX / Mail.com** (`3c.gmx.net`, `3c-bap.gmx.com`, `navigator.gmx.com`)
   - **Gmail Web** (`mail.google.com`)

   Просто выберите нужный сервис в окне CodeSnap и нажмите «Открыть ...» (или держите вкладку почты открытой). Расширение локально прочитает свежее письмо с кодом или ссылкой активации. Если в открытой вкладке есть новое непрочитанное письмо от нужного сайта, CodeSnap покажет кнопку перехода к вкладке почты.

3. **Прямой локальный API без открытой вкладки (опционально)**:
   - **Fastmail**: токен JMAP (`https://api.fastmail.com/*`, только чтение).
   - **Outlook**: пользовательский Client ID приложения Microsoft через OAuth 2.0 PKCE (`https://graph.microsoft.com/*`).

## Конфиденциальность
Пароли от почты нигде не вводятся и не сохраняются. Никакие письма не пересылаются на сторонние серверы, не отправляются и не удаляются. Чтение вкладок почты можно в любой момент отключить в разделе «Настройки → Локальное чтение вкладок почты».
