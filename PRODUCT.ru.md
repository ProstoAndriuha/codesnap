# CodeSnap: Free и Pro

Текущая сборка: **0.7.2, техническое превью**. Функции ниже уже реализованы в коде для проверки, но продажи и ограничение по тарифу пока не включены. Это не оплачиваемая подписка и не опубликованное расширение.

## Ценность для пользователя

На сайте появляется поле для кода из письма. Расширение ищет подходящее свежее письмо в Gmail, показывает код возле поля и вставляет его после одного клика. Поля для кода из приложения 2FA и SMS распознаются отдельно. Кнопки подтверждения операций расширение не нажимает.

## План тарифов для выпуска

| Возможность | Free | Pro |
| --- | --- | --- |
| Поиск кода в одном Gmail-аккаунте | Да | Да |
| Ручной поиск, копирование и вставка одним кликом | Да | Да |
| Несколько Gmail-аккаунтов и выбор аккаунта для сайта | — | Да |
| Код автоматически появляется возле явно определённого email-поля | — | Да |
| Ускоренный поиск во время активной проверки | — | Да |
| Точная привязка письма к сайту и проверка свежести | Да, обязательная защита | Да, обязательная защита |
| Реклама | Возможна в будущей версии после отдельной проверки правил и согласия | Без рекламы |

**Защита не является платной функцией.** Разделение email/2FA, проверка сайта и времени письма, отсутствие автоматического подтверждения операций нужны каждому пользователю.

## Что нужно до начала продаж

1. Получить постоянный ID расширения в Chrome Web Store и настроить OAuth клиентов Google для этого ID.
2. Провести живую проверку Gmail и разных сайтов с тестовыми аккаунтами; отдельно проверить подключение нескольких Google-аккаунтов.
3. Заменить текущий OAuth поток дополнительного аккаунта на вариант, одобренный для публичного продукта после независимой проверки безопасности.
4. Пройти необходимую проверку доступа к Gmail у Google, подготовить страницу продукта, политику конфиденциальности и раскрытие доступа к данным.
5. Подключить платёжного провайдера и проверяемую сервером лицензию/подписку. Проверку тарифа нельзя надёжно делать только локальным флагом расширения.
6. Решить, нужна ли реклама в Free. Если добавлять её позже, она не должна использовать содержимое писем, коды или историю сайтов для таргетинга и не должна появляться поверх формы ввода кода.

Рекламы и платёжного кода в текущей сборке нет. Пользователю не предлагается покупать Pro, пока оплата и выдача прав не работают.
