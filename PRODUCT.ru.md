# CodeSnap 0.7.2

Расширение находит свежие коды из электронной почты и предлагает их рядом с распознанным полем. Вставка или копирование выполняются только по нажатию. Форма сайта не отправляется автоматически.

Gmail, несколько аккаунтов, одиночные и многоячеечные поля, выбор письма, настройка подробной всплывашки. Yahoo, Яндекс, Mail.ru и ручной IMAP доступны через отдельный локальный модуль Windows с Python 3. Outlook временно отсутствует.

В этой версии нет оплаты, рекламы и аналитики. Панель Pro показывает доступные функции превью; продажи и ограничения по тарифам не включены.

Исходники опубликованы на GitHub. Chrome Web Store ещё не опубликован. Google OAuth проверяется отдельно и может ограничивать доступ тестовыми пользователями. Нестандартные поля могут требовать копирования кода.
