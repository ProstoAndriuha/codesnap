# CodeSnap 1.4.0

Расширение находит свежие коды подтверждения и ссылки активации из электронной почты, генерирует сохранённые локально коды 2FA (TOTP) с учётом сдвига часов ПК и переносит 2FA на телефон через офлайн QR-код. Вставка кода и открытие ссылки выполняются только по вашему нажатию.

Все функции работают **100% локально в браузере** без внешних серверов CodeSnap и без установки дополнительных программ:
- Gmail — прямой Google OAuth + Gmail API (несколько аккаунтов);
- Яндекс Почта, Outlook / Hotmail, Yahoo, Mail.ru, Proton Mail, iCloud, Zoho, Рамблер, Fastmail, AOL и GMX — локально с мгновенным Push из открытой вкладки почты без ввода пароля (+ опциональный локальный API для Fastmail JMAP и Outlook PKCE);
- умное распознавание многоформатных кодов (`483 921`, `AB3-9K2`, HTML, тема письма), точное отделение полей почты и 2FA, безопасное извлечение ссылок активации / magic-ссылок;
- локальный 2FA (TOTP) сейф на Web Crypto (`AES-256-GCM` + опциональный PIN), сканер QR / `otpauth://` / текстовых ключей со страницы и Двойная вставка (`Email + 2FA` в 1 клик);
- горячая клавиша `Alt+Shift+V`, контекстное меню, живые таймеры, автоочистка буфера обмена через 45 сек, кнопка скрытия на сайте и автообучение ящика.

В этой версии нет оплаты, рекламы, трекеров и серверного сбора данных. Исходники опубликованы на GitHub.
