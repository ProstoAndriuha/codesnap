CodeSnap 0.8.0

Установленная копия обновляется в прежней папке CodeSnap-Chrome. Нажмите «Обновить» в chrome://extensions, затем заново откройте расширение и обновите страницу сайта.

Настройки → «Почта через CodeSnap Cloud». Яндекс — кнопка «Войти через Яндекс»; Yahoo/Mail.ru/IMAP — пароль приложения. Python и локальный помощник больше не нужны. Gmail по-прежнему подключается напрямую через Google. Outlook пока недоступен.

Пароли приложений и OAuth-токены облачной почты хранятся зашифрованными на сервере. Перед удалением расширения удалите подключённые Cloud-аккаунты. Старая локальная почта автоматически не переносится.

Новая установка: распакуйте CodeSnap-Chrome.zip в постоянную папку и загрузите распакованное расширение в режиме разработчика. ID установленной копии сохранён. Chrome Web Store ещё не опубликован; для магазина потребуется настройка его фактического ID.

Подключение к реальным ящикам требует вашего согласия на официальной странице или вашего пароля приложения. Проверки сервиса не заменяют такой вход.
