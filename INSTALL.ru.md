CodeSnap 0.7.2

Для установленной копии: файлы уже заменены в прежней папке CodeSnap-Chrome. Нажмите «Обновить» в chrome://extensions и откройте расширение снова. При необходимости перезагрузите страницу сайта.

Новая установка: скачайте CodeSnap-Chrome.zip из GitHub Releases, распакуйте в постоянную папку, включите режим разработчика в chrome://extensions и выберите «Загрузить распакованное расширение». Последующие версии заменяют файлы в той же папке.

Gmail подключается кнопкой входа Google. Yahoo, Яндекс, Mail.ru и ручной IMAP требуют отдельного Windows-модуля CodeSnap-Mail-Setup.zip и Python 3; инструкция в MAIL.ru.md. Outlook временно убран из меню.

94 теста расширения и 7 тестов локального модуля прошли. Это не подтверждение работы на каждом сайте или успешного реального входа во все почтовые сервисы.

Публикация Chrome Web Store ещё не выполнена. Для версии магазина необходимо согласовать фактический ID магазина с Google OAuth и модулем IMAP. Пока Google-приложение в тестовом режиме, вход Gmail может быть ограничен тестовыми пользователями.
