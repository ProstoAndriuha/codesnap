CodeSnap Privacy Policy

Effective October 10, 2026. Version 0.7.2.

CodeSnap finds recent email verification codes and offers insertion only after a user click. Contact: GitHub support.

Data accessed and purpose

With Google authorization, CodeSnap uses gmail.readonly to search recent messages and read their sender, subject, receipt time and body. The permission technically grants broader mailbox read access than the recent verification messages the extension seeks. It cannot send, modify or delete Gmail messages.

On HTTPS pages, the extension inspects the current URL, nearby text, labels and verification fields to identify the requesting website and the target field. It does not access your browser history database or read password fields. Email-code field values may be checked to verify insertion. Page context is processed locally.

Processing and sharing

Gmail API requests go directly to Google. Optional IMAP requests go from a local Windows helper directly to the selected mail provider over TLS or STARTTLS with certificate verification. CodeSnap operates no mailbox-processing server, advertising service or analytics. Email content and codes are not sent to the developer, sold, used for ads or used to train models.

Insertion shares the selected code with the website chosen by the user; copying puts it on the system clipboard. The extension never submits the website form.

Storage and retention

Message bodies and code candidates are kept in active-session memory. Local extension storage retains settings, connected addresses, website-account preferences and accepted sender addresses. Additional Gmail access tokens are held in browser session storage until expiry or session end; Chrome manages the primary account token through its identity API.

The optional Windows helper stores IMAP addresses, server configuration and app passwords in %LOCALAPPDATA%\CodeSnap\Mail\accounts.dpapi, encrypted for the current Windows user using DPAPI. Passwords are not stored in extension storage. It uses Native Messaging without an open network listener. IMAP searches currently read only the Inbox, using read-only selection and BODY.PEEK.

Your controls and deletion

You can pause automatic suggestions, remove connected accounts, revoke Google authorization and uninstall the extension. Removing an IMAP account through CodeSnap deletes its stored credentials. Uninstalling the browser extension alone does not remove the separate Windows helper or its vault; remove those separately if desired. Copied codes may remain on your clipboard until overwritten.

Limited Use

CodeSnap's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and the Chrome Web Store User Data Policy, including its Limited Use requirements.

Security and changes

Website binding, message age and field checks reduce accidental insertion. Sender addresses and brand names are not proof of an email's authenticity; review unfamiliar messages. This policy will be updated when data handling changes.
