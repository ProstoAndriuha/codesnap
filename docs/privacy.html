CodeSnap Privacy Policy

Effective November 18, 2026. Version 1.0.1. Contact: GitHub support.

Purpose and 100% local execution

CodeSnap finds recent email verification codes, confirmation links, and optional local 2FA TOTP codes. It inserts a code, copies it, or opens a confirmation link only after an explicit user click and never submits website forms. Starting in version 0.9.1 and expanded in 1.0.0, CodeSnap operates 100% locally inside your browser with zero developer backend servers, zero external helper executables, zero ads, and zero analytics.

Direct Gmail access

Google OAuth and gmail.readonly let the extension read sender, subject, delivery time, headers and body of recent messages directly from Google APIs. Extra Google tokens use temporary browser-session storage; Chrome manages the primary token. Gmail data never leaves your browser.

Local webmail tab reading and optional local APIs

When Local webmail tabs is enabled in Settings, CodeSnap inspects recent messages on open webmail tabs you already signed into (Yandex, Outlook, Yahoo, Mail.ru, Proton, iCloud, Zoho, Rambler, Fastmail, AOL, GMX, Gmail Web) directly in browser memory. No email passwords are ever entered or stored. Optional Fastmail JMAP tokens or Outlook PKCE OAuth client credentials (if explicitly configured by you) communicate directly from your browser with Fastmail or Microsoft Graph APIs using optional host permissions.

Local 2FA (TOTP) vault and clipboard protection

If you choose to add 2FA TOTP secrets or scan a QR setup code locally, your secrets are encrypted with AES-256-GCM in Chrome local storage (with optional PBKDF2 PIN protection keeping the unlocked key only in ephemeral session memory). CodeSnap never uploads 2FA secrets anywhere. When clipboard auto-clear is enabled, copied codes are cleared locally after 45 seconds.

Storage and Limited Use

Local settings, accepted senders, per-site preferences, muted sites, and encrypted local 2FA entries are stored only in Chrome local storage. CodeSnap's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including Limited Use requirements, and the Chrome Web Store User Data Policy, including Limited Use requirements.
