English

Найти. Проверить. Вставить.

Подключите Gmail, запросите свежий код на сайте, проверьте найденное письмо и вставьте код одним нажатием. CodeSnap не отправляет форму сайта.

Несколько аккаунтов. Понятные подсказки.

Выберите почту для каждого сайта. Включите подробную всплывашку, чтобы видеть отправителя, аккаунт, возраст кода и выбирать подходящее письмо.

Дополнительная почта через IMAP на Windows

Yahoo, Яндекс, Mail.ru и ручной IMAP требуют Python 3 и отдельного локального модуля. Gmail работает без него. Outlook в этой версии недоступен.

Конфиденциальность при работе с кодами

Письма обрабатываются в браузере или на вашем компьютере. Нет сервера обработки почты CodeSnap, рекламы и аналитики. Подробности — в политике конфиденциальности.

Доступность подключения

Проверка Google OAuth проходит отдельно от проверки Chrome Web Store. Пока Google-приложение в тестовом режиме, Gmail может быть доступен только добавленным тестовым пользователям.
